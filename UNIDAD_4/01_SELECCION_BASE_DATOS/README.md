# Etapa 1: Selección y Caracterización de la Base de Datos del Proyecto
## Problema Seleccionado
La deserción universitaria temprana genera pérdidas económicas institucionales y frustración social. Este proyecto modela predictivamente el riesgo de abandono estudiantil en el primer año académico.
## Justificación
Permite a los comités de tutoría y bienestar universitario intervenir oportunamente ofreciendo becas y apoyo pedagógico focalizado antes de que ocurra la baja definitiva.
## Ficha Técnica del Dataset
- **Nombre:** Predict Students Dropout and Academic Success (UCI Benchmark)
- **Población:** 500 estudiantes de educación superior.
- **Atributos Predictivos:** 5 variables sociodemográficas y de rendimiento primer semestre.
- **Variable Objetivo:** `Abandono_Estudiantil` (0: Graduado/Continuidad, 1: Deserción).
